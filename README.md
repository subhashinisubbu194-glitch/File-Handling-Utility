# File Handling Utility in Java

## Task 1 - CodTech Internship

### Objective

Develop a Java program to demonstrate file handling operations such as creating, writing, reading, and modifying a text file.

### Description

This project implements a File Handling Utility using Java. The program performs the following operations:

1. Creates a text file (`sample.txt`).
2. Writes data into the file.
3. Reads and displays the file contents.
4. Modifies the file by appending new content.
5. Reads and displays the updated file contents.

### Technologies Used

* Java
* FileWriter
* FileReader
* BufferedReader
* Exception Handling

### Features

* Write data to a file.
* Read data from a file.
* Append new data to an existing file.
* Handle file-related exceptions.

### Output

The program successfully:

* Writes content to the file.
* Displays the original file content.
* Appends additional content.
* Displays the updated file content.

### Learning Outcomes

* Understanding Java File Handling.
* Working with FileWriter and FileReader.
* Using BufferedReader for efficient file reading.
* Implementing exception handling using try-catch blocks.
